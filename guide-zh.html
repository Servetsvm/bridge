桥牌桌 — 使用指南

每个按钮和每项设置的作用。应用地址:https://servetsvm.github.io/bridge/  ·  English

1. 首页

应用总是从首页打开:不会发牌,也不会开桌。

  • 顶部:🌐 语言、⚙ 设置和 ? 本指南。
  • 你的名字和你的体系(2/1、SAYC、Acol、SEF、Precision、Polish Club):体系显示在大厅里你的名字旁边,你的机器人同伴也用这个体系叫牌。
  • 🤖 与机器人打牌(绿色):与机器人打牌(离线也可以)。你的牌桌会出现在大厅里;有人申请加入时由你决定。
  • 🌐 开在线牌桌(蓝色):开一张自己的牌桌,公开或私人。
  • 帮我找座位(黄色):寻找有机器人打牌的牌桌并申请加入;桌主接受后你接替机器人的座位。
  • 🏆 比赛(紫色)、👁 观战(青色)、📋 约定卡(棕色)。
  • 👥 大厅里的玩家和💬 大厅聊天。点击玩家的名字可查看其体系和成绩;点击“今天:…”这一行查看你自己的。

3. 设置

  • 牌面样式:经典或扇形。你的座位:北、东、南或西(你的牌总在下方)。
  • 计分:每副牌也会在 10 张专家级机器人牌桌上打。IMP(队式)或 比赛分 %(双人)。
  • 对手体系:与我们相同或标准(SAYC)。还有机器人速度、叫品解释、自动出唯一合法牌、轮到你时提示音。
  • 练习某个约定:每副新牌都会挑选成你(或同伴)能用上该约定。输入牌局:手动输入(AKQ2.K73.J5.T942、PBN)或从照片读取(照片只在你的设备上读取,读完立即忘记)。

4. 我们的约定卡

选择基本体系(2/1、SAYC、Acol、SEF、Precision Club、Polish Club):会打开该体系的约定,之后每一项都可以修改。你的机器人同伴使用同一体系。点击约定名称可阅读完整的中文说明。

5. 与朋友在线打牌

  1. 大家打开同一个地址:https://servetsvm.github.io/bridge/。
  2. 🌐 开在线牌桌:公开牌桌在大厅列出,任何人都可申请加入;私人牌桌带 🔒:受邀者直接入座,其他人需申请,不允许观战。邀请:点击名字旁的邀请到我的牌桌。
  3. 加入:申请加入,选择同伴、对手或任意空位。申请会带提示音发给桌主;✕ 关闭 — 稍后回复让申请先等待。
  4. 桌主接受或拒绝,并按开始。打牌时桌主可以点击玩家名字将其移出(由机器人代打),也可以用 🚪 关闭牌桌。
  5. 掉线的玩家显示为“离开 · 机器人代打”,10 分钟内回来可重新入座。
  • 玩家名片上的 🤝 结为同伴:开一张牌桌并邀请他坐你对面。👁 观战:公开牌桌无需批准即可观战。
  • 私信:名字旁的 💬;对方不在大厅时,消息会在其到来时送达(⏳ / ✓)。好友:玩家名片上的 ☆。
  • 在线牌桌上的撤回和摊牌:由对方同意或拒绝;摊牌时剩余的牌会在桌上亮出。45 秒未出牌的玩家会收到提醒。
  • 设备之间直接连接;部分移动网络无法连接,通常 Wi-Fi 可以。

6. 比赛

  • 🏆 比赛 → ➕ 新比赛:名称、副数(4–24)、赛制、排名方式(比赛分 % 或 IMP)、保留时间(3 小时、1 天、3 天)。
  • 个人赛:每人在自己的牌桌与机器人打同样的牌;向整个大厅开放;第一副之前选择座位(北、东、南、西)并一直保持。
  • 分桌赛:事先填写每桌的玩家;空位由机器人代打。
  • 🤖 IMP 和 🤖 比赛分 % 两列是你与 10 张机器人牌桌相比的成绩。其他牌桌显示每副牌所有人的定约。比赛结束后可用 🔁 练习这些牌。只有组织者可以用 ✕ 关闭比赛。

7. 同步与安装

成绩和统计可通过 GitHub 上的私人文件在手机和电脑之间同步:设置 → Sync,使用 gist 令牌。令牌相当于密码:不要告诉任何人。

  • 手机:在 Chrome 中打开地址 → 菜单 ⋮ → 添加到主屏幕。离线也能用。
  • 电脑:Chrome 或 Edge 地址栏里的“安装”图标。
  • 新版本会在下次打开时自动安装。
