Puppet Stayman sur 2SA : fonctionnement et exemples

Puppet Stayman : après une ouverture de 2SA, 3♣ demande une majeure quatrième ou cinquième. Les réponses de l’ouvreur, la suite et un exemple.

Le principe

Sur une ouverture de 2SA (20–21, régulière) le Stayman ordinaire ne trouve pas une majeure cinquième chez l’ouvreur. Avec le Puppet Stayman, 3♣ demande les deux : majeure quatrième ou cinquième.

Les réponses de l’ouvreur

  • 3♦ : une ou deux majeures quatrièmes, pas de cinquième.
  • 3♥ : cinq cœurs.
  • 3♠ : cinq piques.
  • 3SA : pas de majeure quatrième.

Après 3♦

Le répondant annonce la majeure qu’il n’a pas, pour que la main forte joue :

  • 3♥ = quatre piques ; 3♠ = quatre cœurs ; 4♦ = quatre cartes dans les deux majeures.
  • 3SA = pas de majeure quatrième (il cherchait seulement une cinquième).

L’ouvreur dit la manche dans la majeure avec le fit, sinon 3SA.

Exemple

Votre partenaire ouvre de 2SA et vous avez ♠Q743 ♥K82 ♦J65 ♣Q94 (8 points). Dites 3♣. Sur 3♦ dites 3♥ (quatre piques) : le partenaire dit 4♠ avec quatre piques, sinon 3SA. Sur 3♥ (cinq cœurs) dites 4♥ : vous en avez trois.
